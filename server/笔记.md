- `process` 是 Node.js 提供的全局对象，包含当前程序运行的信息；`process.env` 是它的一个属性，用来存放环境变量。`.env` 则是我们自己创建的配置文件，默认不会被自动读取。执行 `import 'dotenv/config'` 后，dotenv 会读取 `.env`，把里面的配置加载到已有的 `process.env` 中，例如通过 `process.env.DB_HOST` 读取地址。`dotenv/config` 是一个完整的导入路径，不是两个库；这行代码相当于先 `import dotenv from 'dotenv'`，再调用 `dotenv.config()`，两种写法选一种即可。

- `dotenv/config`是一个完整的模块标识符，不是两个包。`config` 是`dotenv` 包提供的一个子入口。我们如果只引入 dotenv，那么就需要手动调用`dotenv.config() `才能加载.env 文件里的配置了。
